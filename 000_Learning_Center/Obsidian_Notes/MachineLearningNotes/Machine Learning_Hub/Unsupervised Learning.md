# Unsupervised Learning

Unsupervised Learning is a machine learning paradigm where models learn **patterns and structure from unlabeled data**.

Unlike [[Supervised Learning]], the dataset does not contain target labels.

The goal is to discover **hidden patterns, groupings, or representations in data**.

---

# Main Tasks in Unsupervised Learning

Unsupervised learning is typically divided into three major tasks.

---

## Clustering

Clustering algorithms group similar data points together based on **feature similarity**.

Common clustering algorithms:

- [[K Means]]
    
- [[Hierarchical Clustering]]
    
- [[DBSCAN]]
    

Applications:

- customer segmentation
    
- anomaly detection
    
- document clustering
    

---

## Dimensionality Reduction

Dimensionality reduction reduces the **number of features while preserving important information**.

Common techniques:

- [[Principal Component Analysis]]
    
- [[t-SNE]]
    
- [[UMAP]]
    

Applications:

- data visualization
    
- noise reduction
    
- feature extraction
    

---

## Association Rule Learning

Association algorithms find **relationships between variables in large datasets**.

Common algorithms:

- [[Apriori Algorithm]]
    
- [[FP Growth]]
    

Applications:

- market basket analysis
    
- recommendation systems
    

---

# Advantages

- works with unlabeled data
    
- reveals hidden patterns
    
- useful for exploratory analysis
    

---

# Limitations

- harder to evaluate results
    
- patterns may not always be meaningful
    
- sensitive to feature scaling
    

---

# Applications

Unsupervised learning is used in:

- customer segmentation
    
- anomaly detection
    
- topic modeling
    
- recommendation systems
