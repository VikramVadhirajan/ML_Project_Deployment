# Confusion Matrix

A Confusion Matrix is a table used to evaluate the performance of a [[Classification]] model.

It shows the number of correct and incorrect predictions.

---

# Structure

||Predicted Positive|Predicted Negative|
|---|---|---|
|Actual Positive|True Positive|False Negative|
|Actual Negative|False Positive|True Negative|

---

# Components

True Positive (TP)  
Correct positive prediction

True Negative (TN)  
Correct negative prediction

False Positive (FP)  
Incorrect positive prediction

False Negative (FN)  
Incorrect negative prediction

---

# Usage

The confusion matrix is used to compute:

- [[Accuracy]]
    
- [[Precision]]
    
- [[Recall]]
    
- [[F1 Score]]
