# Ridge Regression

Ridge Regression is a regularized version of linear regression that adds an **L2 penalty on model coefficients**.

---

## Objective Function

MSE + λ Σ β²

Where λ is the regularization strength.

---

## Effect

- Shrinks coefficients toward zero
    
- Reduces model variance
    
- Helps handle [[Multicollinearity]]
    

---

## When to Use

- Many correlated features
    
- Overfitting in linear regression
