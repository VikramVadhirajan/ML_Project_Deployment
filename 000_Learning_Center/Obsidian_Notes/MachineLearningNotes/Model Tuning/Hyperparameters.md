# Hyperparameters

Hyperparameters are **configuration parameters set before training a machine learning model**.

They control how the learning algorithm behaves.

Unlike model parameters, hyperparameters are **not learned from the data**.

---

# Examples

Random Forest

- n_estimators
    
- max_depth
    

Support Vector Machines

- C
    
- kernel
    
- gamma
    

Neural Networks

- learning_rate
    
- batch_size
    
- number_of_layers
    

---

# Hyperparameters vs Parameters

Parameters

- learned during training
    
- example: weights in [[Neural Networks]]
    

Hyperparameters

- defined before training
    
- control model learning behavior
