# Apriori Algorithm

## Definition

Apriori is an algorithm used for **association rule mining in large datasets**.

It identifies **frequent itemsets and relationships between items**.

---

## Core Idea

If an itemset is frequent, all its **subsets must also be frequent**.

This principle helps reduce the search space.

---

## Important Metrics

Support

Support(A) = frequency of itemset

Confidence

Confidence(A → B) = P(B|A)

Lift

Lift measures the strength of association.

---

## Applications

- market basket analysis
    
- recommendation systems
    
- retail analytics
